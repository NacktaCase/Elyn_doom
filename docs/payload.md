# 용량

## 제한

파일당 상한이 아니라 리비전 전체 페이로드에 걸리는 타임아웃이다. 간헐적으로
524 가 나며, 재시도하면 대체로 올라간다.

무결이 확인된 최대치는 4.515 MiB 다(2026-08-28 측정). 기본 구성인 5.96 MiB 는
그보다 크므로 올라간다는 보장이 없다.

## 구성별 크기

| 구성 | WAD base64 | 컴포넌트 합계 |
|---|---:|---:|
| 셰어웨어 DOOM, 9판, 소리 | 2,332 KB | 2.60 MiB |
| Freedoom E1, 9판, 소리 | 5,708 KB | 5.96 MiB |
| Freedoom E1, 9판, 무음 | 4,446 KB | 4.70 MiB |
| Freedoom E1M1~E1M5, 소리 | 4,409 KB | 4.67 MiB |
| Freedoom E1M1~E1M3, 소리 | 4,017 KB | 4.28 MiB |

## 줄이는 방법

올라가지 않으면 위 표를 따라 내려간다. 효과가 큰 순서다.

1. `build-wad.cjs` 에서 `--sound` 를 뺀다. 1.26 MB 줄어든다.
2. 싣는 맵을 줄인다. `E1` 대신 `E1M1`~`E1M5` 처럼 지정한다.

같은 9판인데 Freedoom 이 셰어웨어보다 두 배 넘게 드는 이유는 에셋이 커서다.
특히 효과음이 고음질이라 그것만으로 base64 1.2 MB 를 차지한다.

## 프루닝

Freedoom 은 BSD-3-Clause 라 수정과 재배포가 가능하므로 `build-wad.cjs` 가
필요한 럼프만 남긴다. 셰어웨어 IWAD 는 해시로 확인해 프루닝을 거부한다.

프루너는 원래 `-warp` 로 맵에 바로 진입하던 시절에 작성됐다. 타이틀 화면을
살리면서 다음 세 가지를 남기도록 고쳤다. 셋 다 없으면 조작 없이 대기하다가
죽는다.

| 남기는 것 | 없으면 |
|---|---|
| `GENMIDI` | `I_InitMusic` 이 `W_GetNumForName` 으로 찾으므로 음악을 꺼도 부팅되지 않는다 |
| 타이틀·피날레 곡(`D_INTRO`, `D_INTROA`, `D_BUNNY`)과 타이틀·메뉴·인터미션 그래픽 | 해당 화면에 도달하는 순간 죽는다. 현재는 프런트엔드 럼프를 전부 남긴다 |
| 데모가 요구하는 맵 | 아래 참고 |

데모는 헤더에 자기가 어느 맵인지 적어두고 그 맵을 요구한다. Freedoom 의 데모
넷은 E1M6, E2M4, E3M9, E4M6 을 가리키는데 에피소드 1 만 실으면 뒤의 셋이 없다.
`build-wad.cjs` 가 데모를 싣는 맵을 가리키는 것으로 교체한다. 넷 다 E1M6 이
되고 어트랙트 루프는 정상 동작한다.

이 부류는 `doom-boot.cjs` 에 틱을 넉넉히 줘야 잡힌다. `npm test` 대신
`node tools/doom-smoke.cjs --ticks 1200` 을 쓴다.
